# CC 206 Unit 6 Assignment

Flutter profile and pet application by Zyrus Christian E. Canteras, CS 2A.

## Features

- Profile screen with a profile photo, personal details, and biography
- Pet screen with an embedded pet photo and audio playback
- Tab navigation between the profile and pet screens
- Responsive layout for mobile and web

## Run

```sh
flutter pub get
flutter run
```

## Validate

```sh
flutter analyze
flutter test
```
